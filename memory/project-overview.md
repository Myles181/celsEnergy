Single-page marketing site for CELS Energy Limited, a solar installer based in Owerri, Imo State, Nigeria.

**Why:** Business wanted a web presence to capture quote leads from homes and businesses in Southeast Nigeria.

**Stack:**
- React 19 + TanStack Start (SSR-capable) with TanStack Router file-based routing
- Tailwind CSS v4 with custom brand tokens (brand-green, brand-blue, brand-gold)
- shadcn/ui component library (Radix UI primitives)
- Vite 8 + Bun as package manager
- Generated by Lovable (see AGENTS.md, .lovable/)

**App structure:**
- Single route: `src/routes/index.tsx` — the entire landing page
- Root shell: `src/routes/__root.tsx` — sets up HTML shell, QueryClient, fonts (Figtree + Outfit)
- Brand colors defined in `src/styles.css` as CSS custom properties with oklch values

**Page sections (in order):**
1. Sticky nav with mobile hamburger menu
2. Hero with background image and CTA buttons
3. Trust strip (stats: 500+ installs, 10MW+, 24/7 support, 5+ years)
4. Services grid (5 cards: Home, Business, Battery, Inverter, Panels)
5. Packages section (3 tiers: 3.5kVA ₦1.85M, 5kVA ₦2.95M, 10kVA custom)
6. Testimonials (3 reviews)
7. Why CELS / savings callout
8. About section
9. Quote form section (form submits locally — no backend, just sets submitted=true)
10. Footer

**Notable gap:** The quote form (`QuoteForm`) has no actual backend submission — it just sets `submitted=true` on submit. Leads are not captured anywhere.
